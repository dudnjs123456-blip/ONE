# 경계 마을 NPC — VRoid 제작 설정표

지금 차원 NPC 7명은 플레이어가 고르는 몸(은발·은발 소년·남자·여자·핑크)에 옷만 갈아입힌 상태다.
바위·도하·보리는 얼굴과 머리 모양까지 같은 '남자' 몸이다. 아래 설정대로 VRoid Studio 에서 한 명씩 새로 만들어 VRM 으로 내보내면,
게임 연결(용량 줄이기·키 맞추기·기본 표정·소품)은 Claude 가 한다.

## 공통 규칙

- **겹치지 않게 하는 3가지**: 머리 모양(실루엣) · 머리색 · 눈동자 색은 7명이 전부 다르고, 플레이어 몸 6종과도 다르게 한다.
  멀리서 실루엣만 봐도 누군지 알 수 있어야 한다.
- **옷은 VRoid 기본 옷으로 대충만**: 상의(Tops) · 하의(Bottoms) · 신발(Shoes)만 입힌다. 모자·망토·갑옷·앞치마는 게임이 붙이고,
  옷 색과 무늬도 게임이 다시 칠한다. 원피스가 필요한 사람(노아)만 원피스.
  옷 이름은 VRoid 가 붙인 그대로 둔다 (`Tops_`, `Bottoms_` 로 옷을 찾는다).
- **키는 신경 쓰지 않아도 된다**: 게임에서 맞춘다. 다만 체형 느낌(어깨 폭·팔 굵기·배)은 아래대로 만든다.
- **얼굴 그림(텍스처 칠하기)**: 흉터·주근깨·수염·다크서클처럼 적어 둔 것만 얼굴 텍스처에 칠한다. 진하지 않게, 멀리서 느낌만 나게.
- **내보내기**: VRM **1.0**, 텍스처 아틀라스 2048, 흔들림(스프링 본)은 켠 채로. 파일 이름은 `npc-<id>.vrm`
  (예: `npc-noa.vrm`). 다운로드 폴더에 두고 알려 주면 된다.
- 이름 옆 색 코드는 VRoid 색 고르기 칸에 그대로 넣으면 된다 (그라데이션은 뿌리 → 끝).

## 1. 노아 — 차원 마법사 (`npc-noa`)

> 조용하고 신비로운 안내자. 존댓말. "당신이 켠 그 게임, 그건 게임이 아니에요."

| 부위 | 설정 |
|---|---|
| 머리 모양 | **허리까지 오는 곧은 긴 생머리**. 눈썹 위에서 일자로 자른 앞머리 + 얼굴 양옆으로 길게 내려오는 옆머리 두 가닥. 왼쪽 옆머리 하나만 가늘게 땋는다 |
| 머리색 | 짙은 밤하늘 남색 → 끝으로 갈수록 보라 그라데이션 `#1E2347` → `#5B4AA8` |
| 눈 | 반쯤 내리뜬 차분한 눈 (눈꺼풀 살짝 덮기). 눈동자 **옅은 금색** `#E8C56A`, 가운데를 더 밝게. 하이라이트는 별 모양이 있으면 별로 |
| 눈썹 · 속눈썹 | 가늘고 곧은 눈썹, 속눈썹은 아래까지 길게 |
| 피부 | 하얀 편, 차가운 톤 |
| 체형 | 가늘고 긴 팔다리. 어깨 좁게 |
| 옷 (VRoid) | 발목까지 오는 긴 원피스. 게임이 보랏빛 로브 색으로 칠하고 뾰족 모자 · 별빛 망토를 붙인다 |
| 얼굴 그림 | 없음 |

## 2. 마루 — 촌장 · 길드 마스터 (`npc-maru`)

> 마을의 어른. 넉넉하고 점잖은 말투. "반갑네. 이 마을 촌장 마루라네." **지금은 소년 몸이라 나이가 전혀 안 맞는다 → 50~60대로.**

| 부위 | 설정 |
|---|---|
| 머리 모양 | **뒤로 넘긴 반백 머리**, 뒷머리는 목덜미에서 짧게 하나로 묶는다. 귀 앞 구레나룻을 조금 길게 |
| 머리색 | 은회색에 어두운 회색이 섞인 반백 `#B9B6AE` → `#7D7A73` |
| 눈 | 가로로 조금 가늘고 눈꼬리가 처진 너그러운 눈. 눈동자 **따뜻한 호박 갈색** `#8A5A2B` |
| 눈썹 | 굵고 숱 많은 회색 눈썹, 살짝 처지게 |
| 피부 | 햇볕에 그을린 따뜻한 톤 (기본보다 한 단계 어둡게) |
| 체형 | 키 크고 어깨 넓게, 배가 조금 나오게. 목은 굵게 |
| 옷 (VRoid) | 긴팔 셔츠 + 긴 바지 + 부츠. 게임이 금실 조끼 · 진홍 망토 · 깃털 베레모를 입힌다 |
| 얼굴 그림 | **짧게 다듬은 회색 턱수염과 콧수염** (텍스처로), 눈가 주름 두어 줄, 팔자 주름 옅게 |

## 3. 바위 — 북문 기사 (`npc-bawi`)

> 말수 적고 무뚝뚝한 문지기. "오늘도 무사히 돌아와."

| 부위 | 설정 |
|---|---|
| 머리 모양 | **아주 짧은 스포츠 머리**, 옆머리는 바짝 밀고(투블럭) 윗머리만 짧게 세운다. 앞머리 없음 (이마가 다 보이게) |
| 머리색 | 거의 검은 짙은 갈색 `#2B2420` |
| 눈 | 날카롭고 눈꼬리가 올라간 매서운 눈, 눈 크기는 작게. 눈동자 **쇳빛 회청색** `#5D7286` |
| 눈썹 | 굵고 일자로 곧은 눈썹, 미간 가깝게 |
| 피부 | 햇볕에 많이 그을린 구릿빛 |
| 체형 | **7명 중 가장 크고 단단하게**. 어깨 아주 넓게, 팔 굵게, 목 굵게, 허리는 너무 가늘지 않게 |
| 옷 (VRoid) | 긴팔 상의 + 긴 바지 + 부츠. 게임이 사슬 갑옷 · 은빛 어깨 갑옷 · 파란 망토를 입힌다 |
| 얼굴 그림 | **왼쪽 눈썹을 세로로 가로지르는 흉터** 한 줄 (눈썹이 거기서 끊기게) |

## 4. 달래 — 달빛 여관 주인 (`npc-dallae`)

> 다정한 언니. 벼랑 밑에서 주인공을 업어 온 사람. "자, 한 잔 마시고 가."

| 부위 | 설정 |
|---|---|
| 머리 모양 | **물결치는 웨이브 머리를 낮게 한쪽(오른쪽) 어깨로 늘어뜨린 옆 포니테일**. 앞머리는 가르마를 타서 옆으로 흘리고, 얼굴 옆에 잔머리 몇 가닥 |
| 머리색 | 밤빛 적갈색 `#8A3B26` → 끝 `#B5603A` |
| 눈 | 크고 눈꼬리가 살짝 처진 순한 눈. 눈동자 **녹갈색(헤이즐)** `#6F8A4A` |
| 눈썹 | 부드러운 아치형, 머리색보다 조금 어둡게 |
| 피부 | 따뜻한 톤, 보통 |
| 체형 | 보통 키, 어깨 보통. 여성스러운 곡선 조금 |
| 옷 (VRoid) | 긴팔 블라우스 + 발목까지 오는 긴 치마 + 단화. 게임이 크림 블라우스 · 갈색 치마 색으로 칠하고 빨간 두건 · 앞치마를 붙인다 |
| 얼굴 그림 | **코와 볼에 옅은 주근깨** |

## 5. 콩이 — 꼬마 모험가 (`npc-kong`)

> 호기심 많은 마을 아이 (열 살쯤). "우와! 저편 사람이다!"

| 부위 | 설정 |
|---|---|
| 머리 모양 | **덥수룩하고 삐죽삐죽한 짧은 단발** + 정수리에 한 가닥 솟은 바보털. 앞머리는 이마를 반쯤 덮게 들쭉날쭉 |
| 머리색 | 햇볕에 바랜 모래빛 주황 `#D98A3D` |
| 눈 | **동그랗고 아주 큰 눈**. 눈동자 **밝은 풀색** `#4FAE5A`, 하이라이트 크게 |
| 눈썹 | 짧고 도톰하게, 살짝 올라가게 |
| 피부 | 햇볕에 그을린 건강한 톤, 볼에 홍조 |
| 체형 | **아이 체형**: 머리를 크게, 팔다리를 짧게, 어깨 좁게 (게임에서 키를 0.8 배로 줄인다) |
| 옷 (VRoid) | 반팔 상의 + 반바지 + 부츠. 게임이 주황 튜닉 · 초록 망토 · 모험가 모자를 입힌다 |
| 얼굴 그림 | **콧등에 반창고** 하나 |

## 6. 도하 — 먼저 온 저편 사람 (`npc-doha`)

> 서울 막차를 타고 건너오는 20대 후반 직장인. 지쳐 있고 쓸쓸하다. "막차 놓치면 나 여기 못 와."
> 판타지 옷이 아니라 **서울 옷 그대로** — 마을 사람들 사이에서 혼자 튀어 보이는 게 맞다.

| 부위 | 설정 |
|---|---|
| 머리 모양 | **눈썹을 살짝 덮는 덥수룩한 앞머리의 중간 길이 머리**, 손질 안 한 듯 부스스하게. 뒷머리는 목을 살짝 덮는다 |
| 머리색 | 검정 `#16171B` (빛 받는 곳만 아주 옅은 남색 `#2A2F3E`) |
| 눈 | 쌍꺼풀 없는 가늘고 피곤한 눈, 눈꼬리 살짝 처지게. 눈동자 **짙은 갈색** `#3A2A22`, 하이라이트 작게 |
| 눈썹 | 가늘고 살짝 처진 눈썹 |
| 피부 | 햇볕 못 본 창백한 톤 |
| 체형 | 마른 편, 보통 키, 어깨 조금 좁게 |
| 옷 (VRoid) | 긴팔 니트 같은 상의 + 긴 바지 + 단화. 게임이 회색 비니 · 차콜 니트 · 워싱 청바지 · 스웨이드 로퍼로 칠한다 |
| 얼굴 그림 | **눈 밑 옅은 다크서클** |

## 7. 보리 — 여관 요리사 (`npc-bori`)

> 밝고 수다스러운 요리사. 이름처럼 보리빛 머리. "스튜가 딱 알맞게 끓었어."

| 부위 | 설정 |
|---|---|
| 머리 모양 | **짧고 둥글게 말린 곱슬머리** (두건 아래로 옆과 뒤가 보인다). 앞머리는 이마 위로 짧게 |
| 머리색 | 잘 익은 보리빛 밀색 `#C9A25A` → 끝 `#E2C27E` |
| 눈 | 잘 웃는 눈: 동그랗지만 아래 눈꺼풀이 올라와 반달처럼. 눈동자 **꿀색 호박** `#B0782E` |
| 눈썹 | 굵고 둥근 눈썹, 사람 좋아 보이게 |
| 피부 | 따뜻한 톤, **볼 홍조** 진하게 |
| 체형 | **통통하고 다부지게**: 배와 허리 넓게, 팔 굵게, 키는 바위보다 작게 |
| 옷 (VRoid) | 반팔이나 걷어 올린 긴팔 상의 + 긴 바지 + 부츠. 게임이 올리브 셔츠 · 요리사 앞치마 · 흰 두건을 입힌다 |
| 얼굴 그림 | 없음 (홍조만) |

## 받은 뒤 게임에서 하는 일 (Claude)

1. `scripts/shrink-vrm.mjs` 로 텍스처를 1024 로 줄여 `public/models/npc/` 에 넣는다.
2. NPC 전용 몸 목록에 등록한다 (플레이어 코디 창에는 안 나온다).
3. `village.ts` 의 `body` 를 새 몸으로 바꾸고, 키 배율 · 기본 표정(바위는 살짝 찡그림, 보리는 웃는 눈 등)을 맞춘다.
4. 여관 침대 · 대화 초상화 등 몸을 쓰는 곳을 확인하고, 경계 마을 화면에서 7명을 한 장씩 찍어 보여 준다.

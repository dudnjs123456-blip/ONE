# 화풍 기준서: 차원의 밤 배경

프롤로그 배경 두 장(안개 숲 `forest-pano`, 벼랑 전망 `cliff-vista`)을 기준으로 삼는다.
새 배경은 이 문서와 숫자 기준(`art/style-bible.json`)을 둘 다 통과해야 게임에 넣는다.

| 기준 그림 | 원본 | 게임 파일 |
|---|---|---|
| 안개 숲 | `art/library/bg/forest-pano/original.png` | `public/prologue/forest-pano.webp` |
| 벼랑 전망 | `art/library/bg/cliff-vista/original.png` | `public/prologue/cliff-vista.webp` |

## 한마디로
**달밤의 푸른 안개 속, 겹겹이 멀어지는 실루엣. 손으로 칠한 애니메이션 배경.**

## 눈으로 보는 기준
| 항목 | 이렇게 | 이러면 안 됨 |
|---|---|---|
| 색 | 남색 · 청록 · 차가운 은빛 달빛. 따뜻한 색은 작은 점으로만 (마을 창불, 횃불) | 보라·초록이 주인공이 되는 색, 붉은 하늘, 쨍한 원색 |
| 밝기 | 전체적으로 어두운 밤. 제일 어두운 곳도 새까맣지 않은 안개 남색 | 대낮, 새벽 분홍, 새까만 그림자 덩어리 |
| 깊이 | 가까운 것은 진한 실루엣, 멀수록 옅어져 안개에 녹는다 (3~5겹) | 한 겹짜리 평면, 먼 곳까지 또렷한 그림 |
| 빛 | 한 방향(주로 왼쪽 위)에서 오는 달빛·빛줄기. 작은 빛 알갱이(포자·별) 몇 개 | 여러 방향 조명, 렌즈 플레어, 화면 가득한 반짝이 |
| 붓질 | 부드러운 붓 터치, 깨끗한 면, 디테일은 가까운 곳에만 | 사진 같은 질감, 3D 렌더 느낌, 거친 낙서 |
| 내용 | 장소만. 사람·괴물·글자 없음 | 인물, 동물, 간판 글씨, 워터마크 |
| 게임용 | 캐릭터가 서는 장면이면 아래 1/3을 평평한 안개색(#1b2a3d)으로 비운다 | 바닥에 길·돌 같은 디테일 (3D 땅과 어긋난다) |

## 숫자 기준 (scripts/art.mjs 가 자동으로 잰다)
기준 두 장을 잰 값에 여유를 둔 범위.

| 항목 | 안개 숲 | 벼랑 전망 | 합격 범위 |
|---|---|---|---|
| 평균 밝기 | 0.258 | 0.276 | 0.20 ~ 0.34 |
| 가장 어두운 곳 (하위 5%) | 0.133 | 0.143 | 0.08 ~ 0.20 |
| 밝은 곳 (상위 5%) | 0.561 | 0.484 | 0.40 ~ 0.65 |
| 아주 밝은 점 비율 | 0 | 0.003 | 0 ~ 0.012 |
| 주된 색상 (도) | 209 | 213 | 195 ~ 228 (파랑~청록) |
| 채도 | 0.365 | 0.384 | 0.28 ~ 0.50 |

숫자는 색과 밝기만 본다. 붓질·깊이·구도는 눈으로 본다 (Claude 가 기준 그림과 나란히 놓고 확인).
낮 장면이나 다른 분위기(동굴 · 불타는 마을 등)가 필요해지면 기준을 따로 하나 더 만든다.
